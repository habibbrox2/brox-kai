# Brox Kai v2.0 — Logo Pack

Palette:
- Navy Blue: `#0B2B5B`
- Cyan: `#00D1E8`
- Supporting blue: `#168BDB`
- White: `#FFFFFF`

## Contents
- `app-icons/`: PNG app-icon exports at common sizes (16–1024 px).
- `wordmarks/`: light/dark wordmark and mark previews cropped from the generated brand board.
- `vector/brox-kai-monogram.svg`: scalable, editable geometric SVG interpretation of the BK monogram.
- `source/brox-kai-branding-board.png`: original generated branding board.

## Notes
- The wordmark and preview crops are raster images taken from the branding board, so they may include some of the board's surrounding background.
- The SVG is a clean vector interpretation of the chosen BK concept; it is not an exact vector trace of the generated image.
- Before production release, inspect icon crops at small sizes and test Android adaptive-icon safe areas. For a production app, consider supplying separate foreground/background layers for adaptive icons.
- No source project files, Git repository, commits, pushes, tags, or deployments were changed.
