# Brox Kai v2.0 — Brand Name Usage

## Canonical name

**Brox Kai v2.0** is one complete product and brand name. The text `v2.0` is part of the name; it does not identify an app, project, or release version.

## How to present it

- Write the full name as `Brox Kai v2.0` in product titles, onboarding, store copy, documentation, marketing, and sponsorship content.
- Keep `v2.0` on the same visual level as `Brox Kai`: the same typeface, baseline, weight, and color treatment unless an approved wordmark defines otherwise.
- Do not put `v2.0` in a badge, parenthesis, superscript, secondary label, or separate version field.
- `Brox Kai` may be used as a short form only after the full name has been established in the same context.

## Technical versions and releases

Build numbers, Git tags, package versions, and release labels are technical metadata. Present them separately from the product name, for example:

```text
Brox Kai v2.0
Build 2.0.0
```

Never use a technical build number to redefine, shorten, or split the product name.

## UI guidance

- App headers, splash screens, dashboard greetings, and Settings titles should display `Brox Kai v2.0` as one name.
- Use the approved full wordmark whenever there is enough room. Use the BK icon alone in constrained spaces such as app icons and compact navigation.
- Ensure screen readers announce the complete name as “Brox Kai v two point zero”.
