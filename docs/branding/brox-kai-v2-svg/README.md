# Brox Kai v2.0 — SVG Vector Reconstruction Pack

Use **Brox Kai v2.0** as one complete brand name. The `v2.0` text is part of the name, not a separate version badge. See [brand name usage](../brand-name-usage.md).

## Contents
- `01_Geometric_Symbol/`: primary and simplified geometric symbol.
- `02_App_Icons/`: navy/cyan, light, cyan, and monochrome app icon SVGs.
- `03_Wordmarks/`: editable text-based light/dark wordmarks.
- `04_Monochrome/`: single-color symbol variants.
- `05_Documentation/`: design notes and manifest.
- `06_Brand_Board/`: presentation board showing the logo, wordmark, chat loading state, palette and desktop app use.

## Palette
- Navy Blue: #0B2B5B
- Cyan: #00D1E8
- Electric Blue: #168BDB
- Deep Navy: #06152E
- Charcoal: #1A1F2B

## Important
These files contain real SVG paths, shapes, gradients and editable text; they are not PNGs wrapped inside SVG containers. The BK monogram uses the same core geometry as the Compose loading mark and desktop icon source.
The wordmark uses live text with a system-font fallback. For exact typography consistency, open in a vector editor and convert text to outlines after selecting an approved font.
App icon rounded-square backgrounds are intentional parts of those icon variants; the canvas outside the rounded square remains transparent.
The PNG extraction pack at `../brox-kai-v2-logo/` is kept as a visual reference; prefer these reconstructed vectors for new product use. Platform-specific raster icon generation is still required when refreshing Android, Windows or store builds.
